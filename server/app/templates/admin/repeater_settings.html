Op te vragen parameters

Kommagescheiden lijst van get-parameters van de repeater-CLI. Onbekende parameters leveren gewoon een foutantwoord op en kunnen geen kwaad. Deze lijst stuurt alleen de poller-weg. Beide MQTT-wegen gebruiken de lijst in de firmware (SET_PARAMS) — zowel een node die zichzelf uitleest als een monitor die een gemonitorde repeater over LoRa uitvraagt — dus een parameter die je hier toevoegt bereikt die pas na een firmware-aanpassing.
