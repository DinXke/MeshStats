Repeaters vergelijken

Alle repeaters naast elkaar. De nadruk ligt op wat er uit de pas loopt: bij drie nodes zie je dat zelf nog, bij twintig niet meer, en dan is een node met een afwijkende instelling iets wat je pas ontdekt als er iets misgaat.

afwijkend — deze node zegt iets anders dan de meerderheid. geen antwoord — gevraagd, niets teruggekregen. niet gevraagd — deze parameter staat niet in de uitleeslijst, of er is nooit een ronde geweest.

Er wordt alleen gemarkeerd als er een echte meerderheid is om van af te wijken, en pas vanaf drie nodes met een waarde. Twee nodes die het oneens zijn hebben geen afwijker — ze zijn het gewoon oneens, en beide vakjes kleuren zegt niets.

Kolommen

Wat er te kiezen valt zijn de vaste gegevens plus elke parameter die van minstens één node ooit uitgelezen is. Een parameter die nergens gelezen is staat er niet bij: een lege kolom lijkt op een probleem terwijl er alleen nooit iets uitgevraagd is.
