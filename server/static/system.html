Kanalen

Trackers kunnen hun posities via DM naar de server sturen (standaard), of op een kanaal. De server luistert mee op de kanalen hieronder; MeshTrack zet ze zelf op de server-companion. Elk kanaal krijgt een eigen trackergroep, dus ook een eigen kaart. Let op: een kanaalbericht wordt door het hele net geflood en krijgt geen bevestiging; een DM met een gekende route kost meestal minder zendtijd.

Een naam die met # begint, krijgt zijn sleutel uit de naam (zoals in de MeshCore-app).
Een tracker die op dit kanaal stuurt, krijgt deze regio voor zijn floods.
Op een kanaal kan iedereen met de sleutel berichten sturen, en de afzender is gewone tekst. Met ondertekening (een authsleutel per tracker, via USB gezet) worden valse posities geweigerd. Zet dit alleen uit voor een kanaal waarvan enkel jouw eigen trackers de sleutel kennen.
